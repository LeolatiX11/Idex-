# iDesk

Mini desktop web pensato per iPhone/iPad e monitor esterni.

## Funzioni incluse
- Finestre trascinabili e ridimensionabili
- Barra delle applicazioni
- Menu iDesk
- Widget ora e data trascinabile
- Note salvate nel browser
- Calcolatrice
- Web Apps con iframe + pulsante per apertura esterna
- PWA installabile
- Compatibile con hosting statico come GitHub Pages

## Nota sui siti web
Alcuni siti, inclusi diversi servizi Google, impediscono per sicurezza di essere caricati dentro un iframe.
In quel caso usa il pulsante ↗ per aprire il sito in una nuova scheda.

## Pubblicazione
Carica tutto il contenuto di questa cartella in un repository GitHub e abilita GitHub Pages.
